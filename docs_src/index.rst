========================
PsychoPy plugin for LSL
========================

This project is in the planning stage. Its first goal is to explore sending messages over LSL from PsychoPy so that they can be included in the shared data file. This functionality has not been implemented.

The pages below describe example components and interfaces inherited from the PsychoPy plugin template. They are scaffolding, not features of the planned LSL messaging function.
